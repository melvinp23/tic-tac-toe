# Tic-Tac-Toe

A simple two-player tic-tac-toe game that runs in your web browser.

## How to play

- Players take turns placing **X** and **O** on the 3×3 board.
- Get three marks in a row—horizontally, vertically, or diagonally—to win.
- If all cells are filled and nobody wins, the game ends in a draw.
- Click **Restart** to start a new game.

## Run the game

Open `index.html` in a web browser. No installation or build step is required.

## Built with

HTML, CSS, and JavaScript.
